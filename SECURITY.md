# Security

Please report a vulnerability privately, through this repository's **Security** tab ("Report a vulnerability"), not in an issue or a
pull request. Say what is affected (a page, an API, a workflow), how to reproduce it, and what an attacker could do.

Test only against your own local copy (see README.md) or with your own account, and never read, change or delete other people's data
(diaries, profiles, scores) on paibot.app.
