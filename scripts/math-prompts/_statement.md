言葉で答える問題（kind "statement"）。作図の手順や、証明の空欄にあてはまる語句・条件を選ぶ問題を作る。計算式ではない。
出力全体は {"problems": [問題, 問題, ...]} の形（配列だけを出力しない）。出力する各問題は次の形（id・setId・position・published・reviewedAt は出力しない）:
{"kind": "statement", "question": "0", "given": null, "steps": [], "choices": ["1", "2", "3", "4"], "answerIndex": 0,
 "statement": {"ja": {"prompt": "...", "options": ["...", "...", "...", "..."], "explanation": "..."}, "en": {...}, "zh": {...}}}
- question は必ず "0"、choices は必ず ["1", "2", "3", "4"]、steps は []。
- statement の ja・en・zh は内容が完全に一致すること（数値・記号・図の文字・選択肢の順番も同じ）。
- prompt は図の状況（点や線の名前）を言葉で説明する。図は付かないので、問題文だけで解けるように条件を全部書く。改行は "\n" で区切ってよい。最大800文字。
- options は4つ、互いにちがう内容で、正解が1つだけになるようにする。各160文字以内。誤答は学習者がしがちな誤り（条件の取り違え、順番の取り違え、似た定理・手順との混同）。
- answerIndex は正解の位置（0〜3）。5問の中で位置が偏らないようにする。
- explanation は正解の理由を1〜3文で書く（500文字以内）。
- 用語は日本の学習指導要領に合わせる（三角形の合同条件、相似条件、仮定・結論など）。en・zh は教科書で使われる標準的な用語にする。
- 既存の問題（重複を避けること）と同じ内容にしない。
