平均値の定理とロピタルの定理（大学）。5問を mvt 3問、ロピタルの定理（kind "calc"、lim(式, x, 値)、0/0 の不定形）2問にする。mvt は question "f; a, b"（f は x の多項式か exp(x)、区間 [a, b]）で、c が区間内にただ1つ。例 "x^2; 0, 2" → 1、"x^3; 0, 3" → sqrt(3)。choices は c の値。steps は平均変化率の計算（"(4 - 0)/(2 - 0) = 2"）。ロピタルの問題は lim((exp(x) - 1)/x, x, 0) や lim((x - sin(x))/x^3, x, 0) の形。
