数学の練習サイトの学習項目ページに載せる「教科書の本文」を、日本語(ja)・英語(en)・中国語(zh)で書く。ページには本文のほかに「学ぶこと」（項目の説明）、「要点」（公式）、練習問題が別にある。本文はその項目を初めて学ぶ人が、読めば練習問題を解けるようになる説明にする。

内容:
- sections: 2〜4節。最初の節は導入（何をするのか、なぜ学ぶのか、前に学んだこととのつながり）。続く節で定義・考え方・手順・公式がなぜ成り立つかを説明する。各節は heading（短い見出し）と paragraphs（1〜4段落）。表示したい公式は formulas（TeX の文字列の配列）に入れ、その後に続ける段落は after に書く。
- 説明は「何を表す量・関係か → 具体的な数で仕組みをたどる → 公式・手順が導かれる理由」の順を基本にする。既習の定義から理由を説明し、「規則だから」「公式に当てはめる」だけで終えない。結論を繰り返すだけの導入や、暗記・反復を勧めるだけの段落は省く。
- 例: 通分は同じ大きさの単位で数えるため、移項は両辺に同じ操作をして解を保つため、微分は短い区間の平均変化率の極限を求めるため。具体例から一般化するときの条件・適用範囲も説明する。
- examples: 例題を2〜3題。やさしい順に並べ、典型的な形と、符号や係数などでつまずきやすい形を含める。note は解き方の要点を1〜2文で。
- 統計・確率・推論・分布などの応用項目では、例題を具体的な状況の文章題にし、計算だけでなく判断や結論まで書く（kind は "reason" とし、prompt・note・reasoning を使う）。純粋な計算項目では計算例でよい。
- mistakes: 空配列にする。画面には表示しない。説明すべき理由や条件は本文・例題に組み込む。
- 内容（扱う範囲）は対象の学年に合わせる。その学年でまだ習わない概念や方法には踏み込まない。学年は扱う範囲を決めるためだけに使い、文章のやさしさには使わない。
- 本文は学習項目の「項目」と「練習問題の例」が扱う内容に合わせる。項目名と問題の式を読み、別の計算（例: 2桁×1桁と2桁×2桁）を混同しない。
- 文体は学年によらず、高校教科書レベルの簡潔な「です・ます」体で統一する。ひらがなの分かち書きや幼い言い回し（「みかん」「こ」など）は使わず、漢字は通常の表記で書く。量・数直線・面積・変化など、対象の意味が分かる具体例を使う。比喩だけで済ませず、具体例のどの部分が式のどの数・記号に対応するかまで説明する。
- heading は「〜とは」「〜の求め方」「〜の手順」のような簡潔な名詞句にする。「同じ単位で数える」「等しさを保って変形する」のように、節で理解する考え方が分かる見出しにする。
- 教科書や参考書の文章・例題を写さず、自分の言葉で書く。数検などの試験や特定の教科書には触れない。
- 3言語で同じ内容・同じ数値にする。各言語で自然な文章と、その言語で一般的な用語を使う。日本語は「です・ます」体。
- 段落の長さは ja・zh で150字以内、en で60語以内を目安にする。

文章中の数式（caption も同じ）:
- 文章（heading、paragraphs、after、note）の中の数式は必ず $...$ で囲んだ TeX で書く（$x^2 + 5x + 6$、$(x + 2)(x + 3)$、$2 \times 3$）。$ の外に ^ _ \ を書かない。数字だけ（12、3 と 4）は $ なしでよい。
- formulas の TeX も同じ書き方（$ は付けない）。JSON の中なので \ は \\ と書く。

- examples の計算例は kind・question・steps・note。
  - 図形・文章題・証明など、式だけでは条件が分からない例題には prompt（ja/en/zh の問題文）を必ず付ける。必要な条件と求めるものを問題文に書き、note は解き方の説明にする。
  - □を使う例題と間違いは style: "box" を付ける。検算用の question・steps・wrong・right では x を使い、画面では x がすべて □ と表示される。ここに TeX の \\square や記号 □ を直接書かない。note・prompt などの文章では $\\square$ と書く。
  - kind "value": 計算・展開・整理。question は式、steps は "a = b = c" の形の行（1〜6行）で、どの式も question と等しい。
  - kind "factor": 因数分解。"value" と同じで、最後の式はそれ以上因数分解できない積の形。
  - kind "solve": 方程式。question は "2*x + 3 = 7"、連立方程式は "x + y = 5, x - y = 1"。steps の各行は、question と同じ解をもつ方程式・連立方程式（"2*x = 4"）か、最後の行の解（"x = 2"、解が2つなら "x = 3, x = -3"、連立なら "x = 3, y = 2"）。
- mistakes の各項は wrong・right・note。wrong は成り立たない等式（"x^2 + 5*x + 6 = (x + 1)*(x + 6)"）、right は同じ左辺で正しい等式。方程式の解き間違いなら question（方程式）を足し、wrong は誤った解、right は正しい解（"x = 2"）にする。
- 文章で書く手順の説明は note に入れ、steps と wrong・right には式だけを書く。
- 証明・合同条件の判断・論理など、計算式では表せない例題は kind: "reason" とし、prompt（問題の条件と目標）、reasoning（1〜6個の推論の段落の配列）、note（結論または要点）をすべて ja/en/zh で書く。この形式には question・steps を付けない。証明を無関係な計算問題や答えが既に書かれた方程式で代用しない。辺 AB や論理記号は、この形式の文章中の TeX に書ける。
- 式の誤計算ではなく推論・定義の誤りを示す mistakes は kind: "reason" とし、wrong・right・note をそれぞれ ja/en/zh の文章にする。question は付けない。誤りの主張と正しい主張を、条件を含めて対比する。
- question・steps・wrong・right は TeX ではなく上記の機械用の書式。掛け算は必ず *、割り算は : または /、引き算は - を使う。×、÷、−、\\times、\\div、\\frac、\\text をこれらの欄に直接入れない。画面では : が ÷、* が掛け算の記号に変換される。文章欄の数式だけは TeX を使う。
- 計算例の式の書式には、論理記号や y' のような未知関数の微分方程式は含まれない。そのような例題は reason の形式で、必要な式を TeX で書き、推論や解法を省略せず説明する。計算例は SymPy、文章による証明や推論は独立したレビュー役が検証する。

図（任意）:
- 図がないと分かりにくい説明にだけ付ける。1項目に 0〜3 個。数と式だけで足りる説明には付けない。図は sections[].figures（節の公式のあとに表示）か、examples[].figure（例題の式の下に表示）に置く。
