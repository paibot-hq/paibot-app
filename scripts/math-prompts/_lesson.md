数学の練習サイトの学習項目ページに載せる「教科書の本文」を、日本語(ja)・英語(en)・中国語(zh)で書く。ページには本文のほかに「学ぶこと」（項目の説明）、「要点」（公式）、練習問題が別にある。本文はその項目を初めて学ぶ人が、読めば練習問題を解けるようになる説明にする。

内容:
- sections: 2〜4節。最初の節は導入（何をするのか、なぜ学ぶのか、前に学んだこととのつながり）。続く節で定義・考え方・手順・公式がなぜ成り立つかを説明する。各節は heading（短い見出し）と paragraphs（1〜4段落）。表示したい公式は formulas（TeX の文字列の配列）に入れ、その後に続ける段落は after に書く。
- examples: 例題を2〜3題。やさしい順に並べ、典型的な形と、符号や係数などでつまずきやすい形を含める。note は解き方の要点を1〜2文で。
- mistakes: よくある間違いを1〜3個。学習者が実際にしがちな誤りにし、note でなぜ誤りか、どう直すかを説明する。
- 対象の学年に合った言葉と内容にする。その学年でまだ習わない用語や方法は使わない。ほかの学習項目（下に一覧）で扱う内容には深入りしない。
- 教科書や参考書の文章・例題を写さず、自分の言葉で書く。数検などの試験や特定の教科書には触れない。
- 3言語で同じ内容・同じ数値にする。各言語で自然な文章と、その言語で一般的な用語を使う。日本語は「です・ます」体。
- 段落の長さは ja・zh で150字以内、en で60語以内を目安にする。

文章中の数式:
- 文章（heading、paragraphs、after、note）の中の数式は必ず $...$ で囲んだ TeX で書く（$x^2 + 5x + 6$、$(x + 2)(x + 3)$、$2 \times 3$）。$ の外に ^ _ \ を書かない。数字だけ（12、3 と 4）は $ なしでよい。
- formulas の TeX も同じ書き方（$ は付けない）。JSON の中なので \ は \\ と書く。

{{grammar}}
- examples の各題は kind・question・steps・note。
  - kind "value": 計算・展開・整理。question は式、steps は "a = b = c" の形の行（1〜6行）で、どの式も question と等しい。
  - kind "factor": 因数分解。"value" と同じで、最後の式はそれ以上因数分解できない積の形。
  - kind "solve": 方程式。question は "2*x + 3 = 7"、連立方程式は "x + y = 5, x - y = 1"。steps の各行は、question と同じ解をもつ方程式・連立方程式（"2*x = 4"）か、最後の行の解（"x = 2"、解が2つなら "x = 3, x = -3"、連立なら "x = 3, y = 2"）。
- mistakes の各項は wrong・right・note。wrong は成り立たない等式（"x^2 + 5*x + 6 = (x + 1)*(x + 6)"）、right は同じ左辺で正しい等式。方程式の解き間違いなら question（方程式）を足し、wrong は誤った解、right は正しい解（"x = 2"）にする。
- 文章で書く手順の説明は note に入れ、steps と wrong・right には式だけを書く。
