式は次の書き方だけを使う（画面ではこの文字列から数式を表示し、SymPy で答えを確かめる）。
- 数は整数か小数（0.25）。負の数は -3。文字は a〜z の1文字（x, y など）。
- 演算は + - * / : ^ と ( )。かけ算は必ず * を書く（2x ではなく 2*x）。/ は分数として表示、: は ÷ として表示される。^ は累乗（x^2）。
- 平方根は sqrt(2)。それ以外の関数や記号（π、%、×、÷、全角文字）は使わない。
- 分数の分子・分母が式のときはかっこで囲む（(x + 1)/2）。
問題の形式 kind は次のどれか:
- "calc": question の値を求める。choices は値の式（例 "11/12"、"3*sqrt(2)"、"0.6"）。given がある場合だけ、その値を代入して計算する（例 "x = 3, y = -2"）。
- "expand": question を展開・整理した式を選ぶ。正解の choice は展開して整理した形で書く（例 "x^2 - 2*x - 15"）。
- "solve": question は方程式（"2*x + 3 = 7"）。連立方程式は ; で区切る（"x + y = 5; x - y = 1"）。choices は解: 文字が1つなら値をコンマ区切り（"-2, 5"）、連立なら "x = 1, y = 2"。
choices は数学的に互いに異なる4つで、正解は1つだけ。分数は約分した形で書く。正解だけ書式が異なるなどの手がかりを作らない。answerIndex（0始まり）は0〜3をばらけさせる。
given を使わない問題は "given": null にする。
出力形式: {"problems":[{"kind":"calc","question":"2/3 + 1/4","given":null,"choices":["11/12","3/7","3/12","5/6"],"answerIndex":0}]}
