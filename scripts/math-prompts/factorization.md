中学3年生向けの因数分解4択クイズを作ります。
問題は x² + ax + b = (x + p)(x + q) の形で、p, q は0以外の整数。
同じ式（同じ a, b）を出さず、p, q の組み合わせと符号のパターンをばらけさせる。
各問の choices は [p, q] の整数ペア4つで、(x + p)(x + q) を表す。0は使わない。
正解は1つのみ。4つとも数学的に異なるものにする。p, q の順番を入れ替えただけのものは同じ選択肢として扱う。
誤答は両方または片方の符号を逆にする、和と積を取り違える、数を1ずらすなど具体的な誤概念から作り、展開すると元の式と一致しないことを確かめる。
正解だけ書式が異なる手がかりを作らない。answerIndex（0始まり）は0〜3をばらけさせる。
