命題の否定と対偶（数学I、kind "logic"）。5問、which は contrapositive 3問・negation 2問。question は "x > 2 => x^2 > 4"（contrapositive）、"x > 1 and x < 3"、"x = 1 or x = 2"、"x >= 2 => x^2 >= 4" など x についての条件。choices も同じ記法の条件（"x^2 <= 4 => x <= 2"）。対偶は「否定どうしを入れ替えて向きを逆にした」もの。誤答は逆（Q => P）、裏（not P => not Q）、否定の and/or の取り違えから作る。正解と同値な選択肢はちょうど1つ、4つの選択肢は互いに同値でない。steps は [] でよい。
条件に abs やかっこつきの式は使わない（x^2、x*x、x + 1 などのかっこなしの式だけ）。
