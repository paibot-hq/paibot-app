中学1年生向けの正負の数の4択クイズを作ります。
答えと choices は整数。わり算は途中も含め必ず割り切れること。
expression は整数・+ - * / ( ) と半角スペースのみ。かけ算は *、わり算は /。負の数は必ず (-3) のようにかっこで書く。
計算問題の word は null。文章題を指定された場合は expression を問題文から一通りに読み取れる解法の式にし、word に ja・en・zh（簡体字）それぞれの prompt と unit を含める。
文章題は3言語で数値・意味・単位を一致させ、英語の unit は答えに合った単複形にする。条件を明確にしてお金の話は避ける。
choices は異なる整数4つ、正解は1つのみ。誤答は符号のミス、かっこの無視、優先順位の誤りなど具体的な誤概念から作る。
正解だけ書式が異なる手がかりを作らない。answerIndex（0始まり）は0〜3をばらけさせる。
