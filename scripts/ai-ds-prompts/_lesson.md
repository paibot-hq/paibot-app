内容:
- sections: 2〜4節。最初の節は導入（何をするのか、何に使うのか、どんな場面で必要になるか）。続く節で定義・考え方・手順と、それがなぜ成り立つか・なぜその手法を使うのかを説明する。各節は heading（短い名詞句の見出し）と paragraphs（1〜4段落）。目立たせたい式は formulas（TeX の文字列の配列、$ は付けない）に入れ、その後に続ける段落は after に書く。
- 説明は「何を表す量・手法か → 小さな具体例で仕組みをたどる → 式や手順がそうなる理由」の順を基本にする。用語の定義を並べるだけ、公式を示すだけで終えない。結論を繰り返すだけの導入、暗記を勧めるだけの段落は書かない。
- 「扱う内容」に挙がっている事項は、本文か例題のどこかで必ず説明する。範囲外（ほかの項目の内容）に深入りしない。触れる場合は1文にとどめる。
- 似た用語・取り違えやすい点（母分散と標本分散、適合率と再現率、過学習と未学習 など）は、違いを条件つきで説明する。
- examples: 例題を2〜3題。やさしい順。具体的な状況（データ・モデル・業務の場面）を prompt に書き、steps に考え方・計算の段落（1〜6個）、answer に結論を書く。
  - 答えが数になる例題には check を付ける: {"expr": 答えを計算する式, "value": answer に書いた数, "tol": 四捨五入の許容幅（小数第2位までなら 0.005、ちょうどの値なら 0）}。answer の文には value と同じ数を書く（25% と書くなら value は 0.25 でも 25 でもよいが、answer に書いた数と一致させる）。
  - 知識・判断の項目では、状況を読んで手法や指標を選ぶ・結果を解釈する例題にし、check は付けない。
- 標準的で正確な内容だけを書く。年号・人名・手法の細部が不確かなものは書かない。試験名や特定の教科書・参考書には触れず、その文章を写さない。
