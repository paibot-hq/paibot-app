調査日 2026-11-24。対象は `paibot-hq/paibot-app` の `origin/main`、コミット `929b7bf`。作業開始時のローカル `app/main` は `119bfe9` で 44 コミット前だった。トップの3つの棚、数学の読み物、AI・データサイエンスとコンピュータサイエンスの演習ページは、その間に入った差分を含む。本計画はリモートの `main` と一致する参照を起点とする。

## v4.0 の方針

- **Learn** で数学・AI・ITを基礎から体系的に学べるようにする。資格は対応する単元のタグや絞り込みとして扱う。
- **Lab** で式やパラメーターを変え、結果を観察できる実験・可視化を提供する。
- **Tools** から既存の便利ツール・アプリを引き続き探して使えるようにする。
- **Play** でゲーム、雑学クイズ、占い・診断、眺めて楽しむアプリを探せるようにする。
- 既存URL、機能、学習履歴、認証基盤を維持する。Phase 0・1 は既存の React Router と Cloudflare Workers 上で進める。
- 有料教材の先行開発は終了する。利用状況、教材の品質、需要を確認してから段階的に収益化を検討する。月商10万〜30万円は長期目標とし、Phase 1 の完了条件は学習体験と検証結果で判定する。

## Phase 0　移行の基準を確定

1. **分類と入口を決める。** Learn は数学・AIの準備済み教材から始め、ITは体系的な教材が揃ってから加える。Lab は数式やモデルを動かせる実験と、SQL・Linuxのような試せる環境を扱う。Tools は計算練習やコード実行など単独で使えるアプリを用途別に案内する。ゲーム、雑学クイズ、占い・診断などは Play にまとめ、`/apps?tag=game` と既存の休憩リンクも維持する。
2. **移行前の動作を記録する。** 3言語のトップ・検索・お気に入り・主要学習ページ・既存 `/approx`・`/apps` の遷移を確認する。旧カテゴリの301、ロケールなしURLの307、言語切り替え、canonical／hreflang／サイトマップ、未公開教材の `noindex` を回帰チェックの基準にする。開発・本番相当の確認はローカルで行う。
3. **測定項目を定義する。** ランキングは既存の入口指標として保持する。Lab は入口の表示から到達、初回の手動操作、設定を変えた再試行、関連教材への遷移を確認する。初回操作率は「操作した実験表示数 ÷ 実験表示数」、再試行率は「設定を変えてもう一度実行した実験表示数 ÷ 初回操作のあった実験表示数」とする。GA4の設定と既存の同意運用を確認してから、集計方法とイベント導入の要否を決める。
4. **初回の方式を決める。** 勾配降下法の原理を学ぶ実験を Lab の独立したアプリにする。既存のツール用レイアウトとテーマを再利用し、Adam を使う近似対決とは関連リンクで行き来できるようにする。

Phase 0 の完了条件は、棚ごとの代表コンテンツ、既存URLと計測の比較基準、Phase 1 の受け入れ条件が揃うこと。GA4管理画面の未確認項目は、イベント追加前に確認する。

## Phase 1　勾配降下法シミュレーターと最初の導線

### 実験の範囲

- `/:locale/gradient-descent` を追加し、実験の入口、説明、式をSSRで表示する。公開カタログの登録から3言語のルート、canonical、hreflang、サイトマップを生成する。既存の `/:locale/approx` と、先に案内した `#gradient-descent` からも関連リンクで開ける。
- 最初の関数は `f(x) = x²`。微分は `f′(x) = 2x`、更新は `xₖ₊₁ = xₖ − η f′(xₖ) = (1 − 2η)xₖ`。初期値と学習率を選んで1ステップ・再生／一時停止・リセットができる。設定変更時は新しい初期状態から始め、軌跡を混ぜない。
- グラフに関数、現在点、たどった点を描き、反復回数、現在の `x`、目的関数値、傾きと更新量もテキストで示す。「傾きの反対方向へ、学習率に応じて進む」と説明し、同じ初期値で学習率を比較できる例を置く。
- 例えば `x₀ = 3` では、`η = 0.05` でゆっくり近づき、`0.25` で速く近づき、`0.5` で1ステップで最小点に着く。`0.75` では左右を行き来しながら近づき、`1` では往復し、`1.1` では離れる。`x₀ = 0` はどの学習率でも静止する。ほかの関数では適切な学習率が変わることを説明する。
- 最小点への到達、十分に近づいたこと、表示範囲外、反復上限を文言で区別する。表示範囲外では停止してリセット可能にし、範囲外に出た事実だけで一般に発散と判定しない。操作時だけ動作するようにし、グラフを見られない場合もテキストから状態を追えるようにする。

### Phase 1 公開後の判断

計測できる期間と母数が揃ってから、Lab の初回操作率・再試行率、Learn への遷移、関連教材の読了や演習完了を確認する。利用者が学習率の違いを説明できるか、繰り返し使う学習項目は何か、どの内容に支払い意向があるかも確認する。これらを `tool_views` の外部入口数と合わせて見て、次に増やす教材、実験の拡張、収益化の検討順を決める。
